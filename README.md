
# Python Task Manager API

My beginner backend project built with Python and FastAPI.

## Features
- Check API status
- Retrieve tasks
- Create new tasks

## Technologies
- Python
- FastAPI
- Uvicorn

## Run locally
Install dependencies:

pip install -r requirements.txt

Start the server:

python -m uvicorn main:app --reload

API documentation:

http://127.0.0.1:8000/docs
